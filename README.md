# Go D Landing Page

Public bilingual marketing website for Go D, a premium ride-hailing platform launching in Riyadh, Saudi Arabia.

## Requirements

- Node.js 20+
- npm 10+

## Local development

```bash
npm ci
npm run dev
```

## Quality checks

```bash
npm run typecheck
npm run build
```

## Branches

- `dev` — active development
- `staging` — pre-production validation
- `main` — production releases
